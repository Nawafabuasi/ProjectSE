FAQ

Good to know

Do I need a crypto wallet to use Nursil?

Yes — Nursil authenticates through MetaMask, so a browser wallet is required to submit or view records.

Is patient data public on the blockchain?

Access is governed by the smart contract's rules; only permitted wallets can interact with sensitive record fields.

What network does Nursil run on?

Nursil is built on Ethereum-compatible infrastructure using Web3.js and Solidity smart contracts.
